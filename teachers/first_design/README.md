# قالب موقع شخصي للمدرسين

قالب موقع تعريفي (صفحة واحدة) لمدرس مصري، مبني بالكامل بـ HTML5 و CSS3 و JavaScript الخالص (بدون أي مكتبات أو أطر عمل)، بتصميم عصري وفاخر، لغة عربية، واتجاه RTL بالكامل.

## البنية

```
teachers/first_design/
│
├── index.html
│
├── css/
│   ├── variables.css     # الألوان والمسافات والخطوط والظلال (CSS variables)
│   ├── animations.css    # الحركات والانتقالات (fade/scale/float/typing/ripple...)
│   ├── style.css         # التنسيقات الأساسية لكل الأقسام
│   └── responsive.css    # تجاوب الموبايل والتابلت والديسكتوب
│
├── js/
│   ├── main.js           # القائمة، مؤشر التمرير، الوضع الليلي، الأسئلة الشائعة، نموذج التواصل
│   ├── animations.js     # الحركة عند التمرير، العداد، تأثير الكتابة، أشرطة المهارات
│   └── portfolio.js      # معرض الصور (Lightbox)، شرائح آراء الطلاب
│
├── assets/
│   ├── images/           # صور بديلة (SVG) قابلة للاستبدال بصور حقيقية عند التخصيص
│   └── icons/
│
└── README.md
```

## الأقسام المتوفرة

القائمة العلوية، قسم البداية (Hero)، الإحصائيات، نبذة عني، المواد الدراسية، لماذا تختارني، المهارات (أشرطة تقدم متحركة)، المسيرة المهنية (Timeline)، الشهادات، معرض الأعمال، آراء الطلاب (Slider تلقائي)، الأسئلة الشائعة (Accordion)، تواصل معي (نموذج مع تحقق JavaScript)، والفوتر.

## التخصيص عند البيع

- استبدال `assets/images/avatar-placeholder.svg` بصورة المعلم الحقيقية، وصور `gallery-*.svg` و`certificate.svg` بصور فعلية من الفصل والشهادات.
- تعديل الاسم، المادة، الأرقام، وبيانات التواصل داخل `index.html` مباشرة (كل المحتوى نصوص عادية بدون قوالب معقدة).
- الألوان والخطوط قابلة للتعديل من مكان واحد فقط: `css/variables.css`.

## المزايا التقنية

- HTML5 دلالي (semantic) مع تسلسل عناوين صحيح و`alt` وصفي لكل صورة.
- تجاوب كامل (موبايل / تابلت / لابتوب / ديسكتوب) عبر `css/responsive.css`.
- وضع ليلي اختياري (الوضع الافتراضي فاتح) يُحفظ في `localStorage`.
- احترام إعداد `prefers-reduced-motion` لتعطيل الحركات لمن يفضل ذلك.
- تحميل كسول (`loading="lazy"`) لصور الأقسام غير الظاهرة في الشاشة الأولى.
- تحقق نموذج التواصل بالكامل عبر JavaScript قبل الإرسال.
